# Physique100

개인용 운동 기록 PWA. 달력에서 운동한 날을 체크하고, 안 한 날은 설정한 시간에 알림.

## 구글시트 동기화 설정
1. 구글 드라이브에서 새 구글시트를 만든다.
2. 확장 프로그램 → Apps Script → `apps-script/Code.gs` 내용을 붙여넣고 저장.
3. 프로젝트 설정(톱니) → 스크립트 속성 → `TOKEN` = 직접 정한 긴 무작위 문자열 추가.
4. 배포 → 새 배포 → 유형 "웹 앱" → 실행 계정 "나", 액세스 "모든 사용자" → 배포(최초 1회 권한 승인).
5. 나온 웹 앱 URL과 위 토큰을 앱의 ⚙ 설정 → 구글시트 동기화에 입력 후 저장.
6. 기존 기록이 있으면 "전체 시트로 올리기", 시트 내용을 복구하려면 "시트에서 불러오기".

코드를 수정해 다시 배포할 때는 "배포 관리 → 편집 → 새 버전"으로 올려야 URL이 유지된다.
